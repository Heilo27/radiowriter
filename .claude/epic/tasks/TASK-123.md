## Description

Several messages exposed implementation details to users. Fixed:

**ContentView.swift:**
- "Contact list parsing not yet implemented" → "Contacts aren't available for this codeplug format yet."
- "Scan list parsing not yet implemented" → "Scan lists aren't available for this codeplug format yet."
- "This category is not yet available for parsed codeplugs" → "This section isn't available for this codeplug format."

**DMRIDLookupView.swift:**
- "Database not loaded" → "Ready to search"

**DMRIDService.swift:**
- "Failed to download database" → "Couldn't download the DMR ID database. Check your internet connection and try again."
- "Download failed: \(error.localizedDescription)" → "Couldn't update the DMR ID database. Check your internet connection and try again."

**RootView.swift:**
- Stripped `error.localizedDescription` from all 6 user-facing error messages
- "Failed to open file: ..." → "The file couldn't be opened. Make sure you have permission to access it."
- "Could not access file: ..." → "The file couldn't be accessed. Make sure you have permission to read it."
- "Failed to save file: ..." → "The file couldn't be saved. Make sure you have permission to write to this location."
- "Failed to read CSV file: ..." → "The CSV file couldn't be read. Make sure it's a valid CSV file and try again."

Note: `programmingErrorDetails` in AppCoordinator is intentionally exposed via a collapsible "Show Technical Details" disclosure group in ProgrammingView — that pattern is correct and was left unchanged.
