## 2. Description

RadioWriter is a free, open-source macOS application for programming Motorola MOTOTRBO two-way radios. It provides codeplug reading and writing, channel and settings editing, import/export (CSV), and radio communication over USB using the XNL/XCMP protocol.

RadioWriter is an independent project. It is **not** affiliated with, endorsed by, or supported by Motorola Solutions, Inc. See [LEGAL.md](../LEGAL.md) for the full non-affiliation statement.
